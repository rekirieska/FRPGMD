# Управление и настройки

## Управление по умолчанию

- Журнал заданий: :key[key.villagerretaliation.open_quest_journal]
- Отслеживание заданий: :key[key.villagerretaliation.toggle_quest_tracker]
- Быстрые команды отряду: :key[key.villagerretaliation.quick_command]
- Фиксация размещения чертежа: :key[key.villagerretaliation.toggle_blueprint_placement_lock] (по умолчанию не назначена)
- Показывать имена крестьян: :key[key.villagerretaliation.toggle_villager_name_tags] (по умолчанию не назначена)
- Обойти экран взаимодействия: по умолчанию Shift + :key[use]

Откройте меню Minecraft **Моды**, выберите **Villager Retaliation** и откройте экран его настроек. В сетевой игре правила игрового процесса задаёт сервер. Параметры отображения и клавиш остаются клиентскими там, где это поддерживается.

К серверным параметрам относятся контракты, зарплата, ограничения работы, репутация, бой, рейды, восстановление, подарки, задания, социальные правила и содержимое наборов данных. К локальным – назначения клавиш, имена над крестьянами, положение HUD, оформление и другие поддерживаемые визуальные параметры.

:::notice{type="info"}
Если это руководство расходится с ценой, порогом, длительностью, заданием или подарком на вашем сервере, доверяйте значению в игре. Серверная конфигурация и наборы данных намеренно имеют приоритет над встроенными значениями.
:::

Дополнительные интеграции:

- **Second Wind:** добавляет раннее поднятие удержанием действия и анимацию ползания для защищённых крестьян без сознания.
